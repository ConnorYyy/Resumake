## Resumake 站点 SEO / GEO 复核（源码 + 线上实测）

产出：`docs/seo-geo-review-2026-11-24.md`（对照 2026-10-21 的 seo-audit.md / geo-audit.md，覆盖 16 页）

技术栈确认：Vue 3 + Vite 8 + `rolldownOptions.input` 多入口预渲染静态 HTML，Cloudflare Workers 静态资源（`assets` binding），落地页为纯静态 HTML + 极轻 JS（`src/landing.ts`）。Monaco 通过 `src/components/CodeEditor.vue` 动态 import 懒加载（2.7MB 不进首屏）。

核心结论：技术 SEO 已接近天花板（URL 规范化 307 正确、robots/sitemap 无误、FAQ schema 与可见文本逐字一致、`validate-seo.mjs` 0 问题）。真正短板是**内容质量**与**中文覆盖**。

关键发现（含证据）：
- P0 `/app/` 的 500 字描述在 `<div id="app">` 内，Vue 挂载即清空 → 渲染态只剩 sr-only H1，thin page
- P0 静态资源 `max-age=0`：`_headers` 只给 `/assets/*` 设 immutable，`/templates/*.webp`(92KB)、`/og/*.jpg`、`/landing.css` 每次重验证
- P0 落地页 Sentry：`support-*.js` 116KB raw / 39.6KB gzip，占落地页 JS 的 98%（自身逻辑仅 853B）
- P0 `og:image:type=image/png` 但文件是 .jpg（3 页）
- P1 上一轮"答案块"改写留下 30+ 处畸形句式："It is 3 things:"、"It means 0 fields"、"1 photo is often discouraged" —— 伤 E-E-A-T 且 LLM 抽取会丢弃
- P1 中文仅 2 页（599/436 词）且 `zh/` 与 `zh/jianli-shengchengqi/` 意图重叠自我竞争
- P1 无 /about /privacy /contact；Organization 只有 3 个 sameAs，无 founder
- P2 无 llms.txt（404）；子页无实体图谱；`%BUILD_DATE%` 注入 dateModified 与 sitemap 手工 lastmod 自相矛盾
