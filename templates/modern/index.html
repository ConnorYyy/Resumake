Modern resume template: colour without losing readability.

A solid header block, uppercase section labels and a thin accent bar beside each role. It reads as current without turning into a two-column poster that ATS software cannot parse.

Use this template Compare all three

What the Modern template looks like.

The header is a filled block in teal (#0f766e by default) with the name in white, the job title beneath it and contact details on one line. The optional photo floats to the right inside the block.

Section headings are uppercase and teal, followed by a hairline that runs to the right edge. Each role or degree sits against a 3 px accent bar, which breaks the page into scannable chunks.

Everything is still one column in the text layer. The colour block and the bars are backgrounds, not table cells, so parsers read the document in normal reading order.

Who the Modern template works best for.

Good fit

  • Software engineering and data roles
  • Product management and product design
  • Marketing, growth and content
  • Startups and scale-ups
  • Anyone whose resume was rejected for looking “too plain”

Where it is a weaker fit

  • Conservative industries such as banking or law, where the colour block can read as informal
  • Applications that will be printed in greyscale — see the note below

You can still switch: the content stays exactly where it is whatever template you pick.

Three things that make this template look right.

  1. Tip 1

    Keep the header block a mid-to-dark colour. The text inside it is white, so pale accents (yellow, light green) drop the contrast below readable levels.

  2. Tip 2

    Keep the accent bar. It is the only decorative element on the page and it is what makes three roles scan as three groups rather than one wall of text.

  3. Tip 3

    Budget about 10% more vertical space than Minimal: uppercase headings and the 3 px bars push content down. If your resume spills onto a second page, set the margin to narrow or the font scale to 95% before cutting content.

Frequently asked questions

Is the Modern template ATS-friendly?

Yes. The colour block and the accent bars are background styling, and the document stays single-column with standard section headings, so the exported text is read in the normal order.

Can I change the header colour?

Yes. One accent setting controls the header block, the section labels and the bars. The default is #0f766e.

Will it still look right when printed in black and white?

The header block prints as mid-grey and the white text stays readable, but the page loses its main visual cue. If the PDF will be printed rather than read on screen, choose a darker accent or use the Classic template.

Does the Modern template support a photo?

Yes, it floats to the right inside the header block, cropped to a 3:4 ID ratio. It is optional and can be turned off.
